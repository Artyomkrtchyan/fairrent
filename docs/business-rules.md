# Границы и бизнес-правила

## MVP

Один город, долгосрочная аренда квартир. Город, валюта, учёт коммунальных платежей и допустимые источники выбираются командой до реализации.

Поток: загрузка → нормализация → дедупликация → географическое обогащение → оценка → сигналы → API → интерфейс → ручная проверка.

## Оценка

- Baseline: медиана цены за м² сопоставимых объектов с учётом периода, района и характеристик.
- ML сравнивается с baseline на одном тестовом наборе.
- Диапазон прогноза проверяется по фактическому покрытию на отложенных данных.
- Статусы: `within_range`, `above_range`, `below_range`, `insufficient_data`.
- Недостаточно сопоставимых данных — отказ от уверенной оценки; пороги выбираются по результатам исследования.
- Индекс отражает цены предложений, а не заключённых договоров.

## Сигналы риска

Ценовые аномалии, противоречия адреса и координат, несогласованные дубликаты, явно обнаруженные требования предоплаты до просмотра. Каждый сигнал содержит правило, основание, дату и версию. Цена сама по себе не является доказательством мошенничества.

## Онтология

Сущности: Property, Listing, Building, District, City, InfrastructureObject, Estimate, RiskSignal, Review. Связи: describes, locatedIn, near, estimatedBy, hasSignal. Географическая близость определяется правилами; её влияние на цену проверяется данными. Формат онтологии и необходимость OWL/RDF уточняются по критериям курса.

## Жизненный цикл

- Объявление и физический объект — отдельные сущности.
- История цен сохраняется.
- Устаревшие объявления становятся неактивными.
- Ошибка сбора не означает снятие объявлений.
- Повторная загрузка не создаёт повторные записи наблюдений.
- Обновление данных еженедельное; оценка доступных данных — по запросу.
- Переобучение отделено от загрузки.

## Качество

Разделение данных по времени; группы дубликатов не пересекают train/test. Метрики: MAE, медианная абсолютная ошибка, покрытие и ширина диапазона, результаты по районам, доля отказов от оценки. Проверка правил риска — на размеченных примерах; без разметки не заявляем точность обнаружения мошенничества.
