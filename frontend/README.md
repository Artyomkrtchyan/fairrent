# Frontend

Catalogue, filters, map, valuation cards, analytics, and review interface. Start with the shared API contract and synthetic responses.

Owner: Mane (@manemazmand), responsible for Frontend, Analytics and the separate [System Administration Lab](../docs/system-administration.md). D01–D09 cover the frontend; S01–S04 cover Linux setup, diagnostics, backup/restore and recovery. Schedule the lab sequentially around frontend MVP priorities. No Ansible is required.

Stack: React, TypeScript, Vite, Leaflet, Recharts, and Playwright. See the [technology stack](../docs/technology-stack.md).
